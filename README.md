# @kibalabs/ui-react-toast

**Moved to `@kibalabs/ui-react/toast`.** This package is no longer maintained.

```bash
npm uninstall @kibalabs/ui-react-toast
npm install @kibalabs/ui-react react-hot-toast
```

Then replace imports of `@kibalabs/ui-react-toast` with `@kibalabs/ui-react/toast`. Styles move from `@kibalabs/ui-react-toast/styles.scss` (`.css`) to `@kibalabs/ui-react/toast/styles.scss` (`.css`).
